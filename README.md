# 影記 / filmnote

台灣在地的觀影紀錄工具。記下你看了什麼片、在哪家戲院看的、花了多少錢，並把觀影行為量化成看得見的軌跡。

> **開發中，尚未上線。** 條款與隱私權政策仍是草案（`docs/legal/`），未經法律意見。

---

## 為什麼要再做一個

Letterboxd 是這個品類的國際標準，但對台灣使用者有三個結構性的缺陷：

**中文片名混亂。** Letterboxd 的 metadata 來自 TMDB，而 TMDB 的繁體中文標題實測只有 **84.4%** 與台灣官方核准片名一致，另有 **10.6%** 根本沒有中文標題。你搜尋《鬼媽媽的假期》會找不到，因為 TMDB 上它叫 `Our Season`。

**完全沒有「電影院」的概念。** 它記錄你看了什麼，不記錄你在哪裡看的。在信義威秀的 IMAX 廳看跟在家裡看是完全不同的體驗。

**無法記錄消費。** 票價、票數、影廳、播放版本，對想回顧「我今年在電影院花了多少、去了幾次、最常去哪家」的人完全不可得。

所以這個專案的資料層有一個明確的主張：**TMDB 是入口，政府開放資料是校正層。**

## 資料

| | 數量 | 來源 |
|---|---|---|
| 作品 | 2,764 | 政府分級資料收斂 + TMDB 比對 |
| 核准紀錄 | 3,116 | 影視局 110–113 年電影片分級 |
| 電影院 | 107 家 / 932 廳 | 影視局全國電影院資料 |
| 有海報的作品 | 2,452（88.7%）| TMDB（熱連結，不轉存）|

**TMDB 比對的實測覆蓋率**（母體為 110–113 年全部 3,116 筆，非抽樣）：命中 90.3%、端到端可用 81.1%。缺口不在歐洲而在日韓——美國 98.4%、法國英國各 94.4%，但日本 78.6%、韓國 77.6%。缺的型態是劇場版／總集篇、演唱會影像作品、以及數位修復重映。

**那 20% 不是失敗指標，是設計 UGC 的依據**：「找不到這部片」是一等公民的使用流程，不是錯誤狀態。

### 兩層作品模型

同一部片會因國語版／日語版／2D／3D 分開核准（113 年實測「中文片名」有 56 組重複），所以核准紀錄不能當作品。以 `certificate` 多對一 `film`，實測收斂掉 **14.3%** 的重複——若以核准紀錄計數，「看了幾部片」的統計會全面失真。收斂最極端的是《TAYLOR SWIFT | THE ERAS TOUR》，**一部片十三張證明書**。

⚠️ **分級證明字號不能當主鍵。** 110–112 年的 CSV 沒有系列前綴，四個系列各自從 001 編號，實測撞號 128 / 143 / 157 筆。改用確定性複合鍵「年度:字號:正規化片名」，在 3,116 筆上唯一，且重跑匯入不會產生重複列。

## 技術

Nuxt 4（公開頁 SSR + ISR、登入後 SPA）· Nuxt UI v4 · Tailwind CSS 4 · ECharts · Supabase（Postgres + Auth + Storage + RLS）· Vercel

### 幾個刻意的決定

**票價存在獨立的一張表。** 不是實作偏好——它讓「未登入者看不到票價」可以在資料庫層強制，而不是靠畫面隱藏。畫面隱藏擋不住直接呼叫 API 的人。

**海報一律熱連結 `image.tmdb.org`，不自行轉存。** TMDB 的訂閱買到的是「合法存取 API 的權利」，不是「合法使用海報的權利」——海報著作權屬片商，TMDB 自身亦不擁有。

**時間存 `date` + `time` 而不是 `timestamptz`。** 使用者記的是「牆上時間」，而貢獻圖與時段熱力圖要的正是那個。存 timestamptz 會讓每一次讀取都要換算，而換算錯誤是靜默的。

**圖表色票定義在 TypeScript，不從 CSS 變數讀。** ECharts 的 zrender 解析不了 `oklch()`／`var()`／`color-mix()`，而 Nuxt UI 4 的 token 正是 oklch。陰險的是它**有時候會動**：連續型 visualMap 會 fallback 成黑色，piecewise 則把字串原樣輸出到 SVG 而看起來正常。

## 驗證

```bash
pnpm test          # 308 個單元測試，離線、以錄製的 fixture 跑
pnpm verify:all    # 36 條端到端斷言，對真實資料庫與 PostgREST
```

`verify:all` 是這個專案累積下來最有價值的東西：**每一條斷言旁邊都寫著它守的是哪一個真的踩過的坑**（`docs/BUILD_PLAN.md` §7 的編號）。看到某條紅了，先讀那句話。

它也刻意配了反向斷言——「未登入者看不到票價」要配一組「本人看得到」，否則把所有人都擋掉也會全綠。**假綠燈比紅燈危險。**

## 開發

需要 Node ≥ 22.12 與 pnpm。

```bash
pnpm install
cp .env.example .env      # 填入 Supabase 與 TMDB 的值
pnpm dev
```

資料匯入管線（政府開放資料 → 正規化 → TMDB 比對 → 種子）：

```bash
pnpm ingest:rating        # 電影片分級及相關資訊
pnpm ingest:cinema        # 全國電影院資料
pnpm seed                 # 寫入 Supabase
```

## 資料來源與授權標示

本專案使用**文化部影視及流行音樂產業局**的「電影片分級及相關資訊」與「全國電影院資料」開放資料，依**政府資料開放授權條款第 1 版**提供。本專案對前述資料進行了正規化、去重與比對加工；加工後的呈現與原始資料可能不同，加工結果由本專案負責，與資料提供機關無關。
