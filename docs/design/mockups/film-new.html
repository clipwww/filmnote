4. 已比對到 TMDB 的作品：沒有海報欄位

SPEC 明寫「已比對到 TMDB 的作品禁止上傳海報——無必要，只增加曝險」。 做法是那一欄根本不出現，不是出現一個停用的欄位。停用欄位等於公告「這裡本來有東西」， 然後逼使用者去想為什麼不能用。

這部片已經比對到 TMDB，海報與詳細資料會自動帶入，不用也不能自己上傳。

5. 只有中文片名擋得住人

欄位必填空的時候
中文片名是 主要動作停用；錯誤顯示在欄位旁邊，不在頁面頂端（§10）
原文片名 / 國別 / 上映年 / 片長 / 海報否 票根卡上那一項就是不存在，不渲染「—」或「未知」佔位（同 §4.3 的票價規則）

擋住人比資料不完整更糟。US-14 寫的是「只需填片名與年份，補資料的成本夠低我才願意做」—— 連年份都不該擋。缺的欄位之後比對到 TMDB 會自己補上（US-18）。
