## 1. 資料來源與顯名標示

### 1.1 政府開放資料

本服務的作品分級資訊（核准中文片名、國別、片長、級別）與全國電影院主檔，
採用**文化部影視及流行音樂產業局**的下列開放資料：

- 「電影片分級及相關資訊」
- 「全國電影院資料」

以上資料依「**政府資料開放授權條款第 1 版**」提供。

本服務對前述資料進行了正規化、去重與比對加工。**加工後的呈現與原始資料可能不同，
加工的結果由本服務負責，與資料提供機關無關。**

### 1.2 TMDB

本服務使用 TMDB 的 API 取得作品的海報、簡介與國際識別碼。

> This product uses the TMDB API but is not endorsed or certified by TMDB.

TMDB 的標誌顯示於本服務每一個公開頁面的頁尾，其視覺份量小於本服務自身的標誌。

**本服務不重製、不轉存 TMDB 的圖片。** 海報以連結方式指向 TMDB 的伺服器。
來自 TMDB 的快取資料保存不超過 6 個月。

### 1.3 使用者補充的資料

本服務片庫中約有一成的作品在 TMDB 上找不到，這些作品由使用者補充。
使用者補充的作品資料與海報，其權利與責任見第 3 節。

## 2. 我們怎麼處理海報

| 情況 | 做法 | 為什麼 |
|---|---|---|
| 已比對到 TMDB 的作品 | 連結至 TMDB，不轉存 | 未重製、未散布 |
| 片庫中沒有的作品 | 使用者可選填上傳，審核後才公開 | 補足約一成的缺口 |
| 已比對到 TMDB 的作品 | **禁止上傳海報** | 無必要，只增加曝險 |
| 沒有海報時 | 以片名文字卡片呈現 | 缺海報不影響核心功能 |

**海報的顯示不置於任何付費牆或登入牆之後。**

## 3. 侵權通知（通知／取下）

### 3.1 聯繫窗口

著作權人或其代理人認為本服務上的內容侵害其著作權者，請透過下列任一方式通知：

- 線上表單：`/legal/dmca`
- 電子郵件：本服務公告之著作權聯繫信箱

### 3.2 通知應載明的事項

為使通知能被處理，請載明：

1. 通知人的姓名與聯絡方式（電子郵件）。
2. 主張受侵害的著作，以及你對該著作享有何種權利。
3. **指明本服務上的哪一個網址或哪一筆內容**涉有侵權。
4. 你相信該內容之使用未經授權的陳述。
5. 通知內容為真實的聲明。

### 3.3 我們收到通知後會做什麼

1. **立即移除**該內容，使其不再對外公開。
2. **轉送通知**給該內容的提供者。
   ⚠️ **轉送的內容包含通知人的姓名與電子郵件地址。** 這是必要的：內容提供者若要
   提出回復通知乃至日後應訴，必須知道對方是誰。提出通知即表示你理解並同意此事。
3. 依第 4 節處理回復通知。
4. 依「服務條款」第 6 節計入三振。

**你提出的通知，你本人事後無法在本服務上讀取。** 這是刻意的設計：這張表只進不出。
需要留存者請自行保存副本。

## 4. 回復通知

內容提供者認為其內容並無侵權情事者，可提出回復通知。

1. 本服務將回復通知轉送著作權人。
2. 著作權人自轉送日起 **10 個工作日**內，應向本服務提出「已就該爭議提起訴訟」之證明。
3. 逾期未提出者，本服務將於 **14 個工作日**內回復該內容。
4. **回復時，內容的公開狀態還原成取下前的樣子**，而非一律設為公開；該次三振一併作廢。

第 4 點值得說明：一部原本設為私密、從未公開過的作品若被取下後「回復成公開」，
那不是回復，是把它發布出去。所以本服務在取下時會記下當時的狀態，回復時原樣寫回。

## 5. 重複侵權

見「服務條款」第 6 節的三振條款。

## 6. 資料錯誤回報

片名、電影院資訊有誤，或某家電影院已歇業，都可以透過服務內的回報功能告知。
**這與著作權通知是不同的流程**，不要混用——資料錯誤回報不會觸發取下。
